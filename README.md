# bilginsenol.github.io

Personal site, served by GitHub Pages.

| Path | URL | Source |
|------|-----|--------|
| `index.html` | https://bilginsenol.github.io/ | Custom minimal home page |
| `tptf/` | https://bilginsenol.github.io/tptf/ | Paper page, based on the [Academic Project Page Template](https://github.com/eliahuhorwitz/Academic-project-page-template) |

`.nojekyll` at the root disables Jekyll processing — the whole site is plain static HTML.

## Local preview

```bash
python3 -m http.server 8000
# home → http://localhost:8000/
# tptf → http://localhost:8000/tptf/
```
